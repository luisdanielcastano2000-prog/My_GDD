# Logos

- `my-gdd-logo-horizontal-*`, `my-gdd-logo-vertical-*`, `my-gdd-logo-nombre-*`: el logo con el nombre en trazos. `-claro` va sobre fondos claros (nombre #1C1B26, punto #E8603C); `-oscuro`, sobre fondos oscuros o índigo (nombre #FDF8F9, punto #FF8E6E).
- `my-gdd-icono.svg` / `my-gdd-icono-1024.png`: icono con las esquinas redondeadas, para presentaciones y documentos.
- `my-gdd-icono-cuadrado.svg`: icono sin redondear, para cuando el sistema aplica su propia máscara.
- `ic_launcher_foreground.svg`, `ic_launcher_background.svg`, `ic_launcher_monochrome.svg`: capas del icono adaptativo de Android (108 dp, dibujo dentro de la zona segura de 66 dp). El monocromo es para los temas del sistema (Android 13+).
