# TextField

Outlined text field de M3: 56 px de alto, radio `corner-extra-small`.

- Etiqueta siempre visible (flotante), en `on-surface-variant`; en foco y error toma `primary` o `error`.
- Error: borde de 2 px en `error` y un mensaje que dice cómo arreglarlo, nunca solo «Invalid».
- Texto de ayuda debajo (`body-small`) cuando hace falta: «At least 8 characters.»
- Las contraseñas llevan un icon button para mostrarlas u ocultarlas.
