# IconButton

Botón de solo icono, siempre con `aria-label`.

- Zona táctil de 48 × 48 (`touch-target`) aunque el icono sea de 16 (lápiz de renombrar) o 20.
- **Standard**: color `on-surface-variant`. Menú ⋮ dentro de cada tarjeta, búsqueda, back.
- **Toggle**: en la floating toolbar del editor (H, B, I, lista); activo con fondo `secondary-container`.
- El lápiz pequeño (16 px) va pegado al nombre que renombra, dentro de su tarjeta.
