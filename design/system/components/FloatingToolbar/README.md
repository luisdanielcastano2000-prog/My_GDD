# FloatingToolbar

Floating toolbar de M3 Expressive para el editor de bloques, con un FAB al lado.

- Botones toggle: tamaño de texto, negrita, cursiva, lista. Actúan sobre la sección en la que está el cursor.
- FAB: check (Save) o doble check (Mark as reviewed) cuando el bloque tiene partes por revisar.
- Sustituye a la barra de navegación en el editor.
