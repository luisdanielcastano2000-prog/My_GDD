# FAB

Botón flotante para la acción de crear de cada pantalla.

- **Extendido** (icono + texto): New GDD, Department, New note, Invite member. Abajo a la derecha, 16 px por encima de la barra de navegación.
- **De icono**: en el editor, junto a la floating toolbar. Check = Save; doble check = Mark as reviewed.
- Fondo `primary-container`, texto `on-primary-container`, radio `corner-large`, sombra `elevation-3`.
- Un solo FAB por pantalla.
- **Movimiento:** el «+» gira 90° y aparece la etiqueta. `dur-short`, `ease-decelerate`.
