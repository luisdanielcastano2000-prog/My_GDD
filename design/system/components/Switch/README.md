# Switch

Switch de M3: 52 × 32, dentro de una fila de lista con su etiqueta.

- Para ajustes que se aplican al momento: Notifications, High contrast, Reduce motion, Two-step verification, You can reply to me.
- Encendido: pista `primary`, mando `on-primary` de 24 px. Apagado: pista `surface-container-highest` con borde `outline`, mando de 16 px.
- Toda la fila responde al toque; el switch usa `aria-labelledby` con el texto de la fila.
- **Movimiento:** la bola crece al pulsar y se desliza. `dur-short`, `ease-decelerate`.
