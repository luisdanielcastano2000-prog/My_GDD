# Dialog

Basic dialog de M3: `surface-container-high`, radio `corner-extra-large`, acciones en text buttons.

- Renombrar (proyecto, departamento, bloque) y editar un dato (Phone, Country, Time zone).
- Confirmar lo que no se puede deshacer: borrar un proyecto, un departamento o la cuenta, quitar a alguien del equipo. La acción destructiva en `error`.
- Lo que sí se puede deshacer (bloques, notas, recordatorios) no pide confirmación: snackbar con Undo.
