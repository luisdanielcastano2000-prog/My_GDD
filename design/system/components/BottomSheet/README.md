# BottomSheet

Modal bottom sheet de M3: `surface-container-low`, esquinas superiores `corner-extra-large`, asa de 32 × 4.

- **Menú ⋮**: Rename, Move up / Move down (Move left / Move right en proyectos), Delete en `error`. La opción imposible se ve desactivada.
- **Formularios cortos**: Set review date (fecha, hora, repetición, quién), Manage, Invite a member, Profile photo.
- Se cierra tocando el scrim o con Cancel.
- **Movimiento:** sube con `ease-decelerate` y oscurece el fondo. `dur-sheet` al abrir, unos 250 ms al cerrar.
