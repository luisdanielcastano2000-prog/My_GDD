# ButtonGroup

Connected button group de M3 Expressive, para elegir una opción entre 2 y 4.

- Usos: Repeat (Once / Every week / Every month), Who gets the reminder, Theme, Text size, Topic, Role.
- Sin seleccionar: `secondary-container`; las esquinas interiores son `corner-small`, las exteriores redondas.
- Seleccionado: `secondary` con `on-secondary`, totalmente redondo (`corner-full`).
- Semántica: `role="radiogroup"` con un `role="radio"` por opción.
